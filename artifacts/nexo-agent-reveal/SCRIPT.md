# Nexo Agent — “Move from asking to doing”

## Director's treatment
- **Promise:** Nexo Agent turns a request into forward motion; the viewer remembers that it can act, not only answer.
- **Identity:** The supplied NexoAI splash is the brand source of truth: near-black, electric cobalt, white. Display face: Space Grotesk; supporting face: DM Sans; precise system labels in JetBrains Mono.
- **Hero:** The actual supplied Agent Mode footage, framed as an active window and then broken free into a cinematic full-frame reveal. The supplied splash is reserved for the final branded lockup.
- **Motion:** Hard-edged cobalt light cuts, typography that snaps into alignment, and controlled push-throughs that connect the working interface to the Nexo mark.
- **Arc:** Quiet signal → an instruction gains momentum → action resolves into the brand → confident, spacious signature.
- **Payoff:** The finale changes from kinetic process language to the exact supplied Nexo Agent splash image, held as the only complete, still composition.
- **Format:** 16:9 landscape. **Runtime:** 24 seconds, locked after music generation.
