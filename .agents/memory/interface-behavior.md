---
name: Opt-in workspace and sidebar controls
description: User-requested limits on automatically opening the IDE and conversation-button presentation.
---

The IDE should appear only on request, not automatically when Nexo generates code. The new-conversation control should have no visible text and should be integrated into the sidebar.

**Why:** The user explicitly requested an opt-in IDE and a smaller embedded conversation control instead of the prominent text button.

**How to apply:** Keep code generation separate from workspace visibility; opening the workspace is an explicit user action. Retain an accessible label and tooltip on the icon-only conversation button.
